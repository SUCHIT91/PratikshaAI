# Pratiksha AI — Base

Basic Python assistant. Text input leta hai, placeholder logic se process karta hai, reply deta hai.

## Chalaayein
    python3 main.py

## Structure
- main.py   — conversation loop
- brain.py  — processing (placeholder, baad me AI model)
- voice.py  — voice hooks (TTS/STT, Android ke liye)
